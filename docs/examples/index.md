# Examples

Worked setups you can run yourself. Each example is a complete deck together with
the reasoning behind it: what each configuration block does, what the output should
look like, and which knobs are worth varying.

Examples are small by design — a laptop runs one in well under a minute — and the
test harness runs them, so a deck that stops working fails a board rather than
quietly misleading a reader.

An example may carry extended subsections beyond the walkthrough, such as an
analysis page working through the output it produces.
