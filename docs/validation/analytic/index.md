# Analytic Cases

Cases whose reference is a closed-form result, a conservation law, or a convergence
rate — the model is checked against mathematics rather than against a laboratory.
These run anywhere, which makes them the subset continuous integration can rebuild
unaided.

Case families: linear dispersion, isotropy, mass and energy conservation, solitary
wave propagation, the closed-basin standing wave, and still-water rest.
