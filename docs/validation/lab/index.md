# Laboratory Cases

Cases whose reference is measured data from a published flume or basin experiment.
These carry the model against real physics — breaking, runup, harmonic transfer,
sediment transport — and most need more compute than a laptop.

Case families: Synolakis solitary runup, Hansen & Svendsen surf zone, Ting & Kirby
breaking, Beji & Battjes bar, Kobayashi & Lawrence and Pintado-Patino swash.

!!! warning "Redistribution"
    Some laboratory data may not be redistributed. Those cases publish derived
    metrics only, never the digitized source values.
