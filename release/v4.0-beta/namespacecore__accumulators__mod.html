Detailed Description

Accumulates field statistics over a simulation time window using time-step weights \(\Delta t_n\).

Supported statistics are time-weighted mean, root-mean-square (RMS), point-wise minimum, and point-wise maximum. Multiple statistics can be active simultaneously on the same accumulator by calling allocate_stat once per statistic before the accumulation loop.

Time-weighted formulas

Let \(f^{(n)}\) denote the field at time step \(n\) with time increment \(\Delta t_n\). Define the total accumulated time \(T = \sum_n \Delta t_n\).

Mean

\[ \bar{f} = \frac{1}{T} \sum_n f^{(n)} \Delta t_n \]

RMS

\[ f_{\mathrm{rms}} = \sqrt{\frac{1}{T} \sum_n \bigl(f^{(n)}\bigr)^2 \Delta t_n} \]

Min / Max — point-wise extrema over all accumulated steps, unweighted.

  • total_dt \(\mathrel{+}= \Delta t\)

Allocate storage for one statistic.

Must be called after init and before the first accumulate. Safe to call multiple times for the same op; subsequent calls are no-ops if storage is already allocated.

Valid values of op:

op Storage allocated
"min" val_min
"max" val_max
"mean" val_sum
"rms" val_sum, val_sum_sq
Parameters
[in]opStatistic name: "min", "max", "mean", or "rms".

real(sp) function, dimension(:, :), allocatable core_accumulators_mod::get_stat ( class(type_accumulator), intent(in)  this,
character(*), intent(in)  op 
)

Retrieve the final statistic as a 2-D array.

Applies the normalisation formula for the requested op:

op Formula
"min" \(\min\) (already stored)
"max" \(\max\) (already stored)
"mean" \(\bar{f} = \sum f\,\Delta t \;/\; T\)
"rms" \(\sqrt{\sum f^2\,\Delta t \;/\; T}\)

Returns a zero-filled array if the required storage is not allocated or if total_dt <= 0.

Parameters
[in]opStatistic name (same values as allocate_stat).
Returns
Array of shape (dim1, dim2) with the statistic value.
