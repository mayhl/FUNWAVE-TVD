Detailed Description

Generic pre-allocated slot pool for intra-timestep temporary 2-D arrays.

Lifecycle:

  1. Each physics module calls reserve(n)/unreserve(n) during init_compute, mirroring the nesting of acquire/release at runtime. Nested reserves accumulate; peak tracks the high-water mark.
  2. Call finalize(dim1, dim2) once to allocate slots(:,:,1:peak).
  3. At runtime, acquire() returns the first free slot index; release(k) frees it.

GPU note: after finalize, add !$omp target enter data map(alloc: thisslots) Acquire/release operate on host-only in_use(:) and are never called inside kernels.
