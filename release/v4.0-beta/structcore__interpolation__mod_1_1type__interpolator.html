Detailed Description

Stores pre-computed bilinear stencils for a set of query points that are local to the calling MPI rank.

Members are allocated by init and freed by finalize. All index arrays are in ghost-inclusive local coordinates so that gather can index directly into ghost-padded field arrays.

Evaluate bilinear field values at the pre-computed query points.

For each locally owned point \(k\) with lower-left cell index \((i,j)\) and normalised weights \(\alpha, \beta \in [0,1]\), the interpolated value is

\[ f_k = (1-\alpha)(1-\beta)\,f_{i,\,j} + \alpha(1-\beta)\,f_{i+1,\,j} + (1-\alpha)\beta\,f_{i,\,j+1} + \alpha\,\beta\,f_{i+1,\,j+1} \]

where the weights are defined as

\[ \alpha = \frac{x_k - x_i}{\Delta x_i}, \qquad \beta = \frac{y_k - y_j}{\Delta y_j}. \]

See [press2007numerical], §3.6, for the bilinear form on a non-uniform rectilinear grid.

Note
The loop is parallelised with OpenMP (!$omp parallel do). Call a halo exchange before gather so ghost cells contain valid neighbour data.
Parameters
[in]fieldGhost-inclusive 2-D field array; first dimension size must equal local_nx + 2*N_GHOST.
[out]outInterpolated values at the n_points locally owned query points.

Initialise from a set of global query coordinates.

Iterates over all global query points and retains only those that fall within the local subdomain owned by the calling MPI rank. For each retained point the bilinear cell and weights are computed by find_bilinear_cell.

Precondition
gridx, gridy, griddx, griddy must be allocated (call gridinit_spacing first).
Field arrays passed to gather must be ghost-inclusive: first dimension size = local_nx + 2*N_GHOST.
